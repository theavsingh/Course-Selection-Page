## 📖 Overview
This project is a responsive, student-friendly Course Selection Portal built for Assignment 5. It allows users to browse available academic programmes and dynamically select a course, with the choice reflected in real-time on the page.

## 🛠️ Technical Stack
* **HTML5:** Semantic document structure and clean layout.
* **CSS3:** Custom styling, hover states, and mobile-responsive adjustments.
* **JavaScript:** Client-side interactivity, DOM manipulation, and dynamic UI highlighting.

## 📁 Files Included
* `index.html` - The main structure of the web page.
* `style.css` - All styling and responsive layout rules.
* `script.js` - The logic for course selection and the dynamic banner.
